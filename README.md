สไปรต์เคลื่อนที่ตามตำแหน่งเมาส์ (Translation)ปุ่ม 1 / 2 / 3 / เปลี่ยนสีเป็น แดง / เขียว / น้ำเงิน  ลูกศร ← / →หมุนสไปรต์ (Rotation) ลูกศร ↑ / ↓ขยาย / ย่อสไปรต์ (Scale)
Translation, Rotation และ Scale ใน Interactive Computer Graphics

การแปลงรูปทรง (geometric transformation) ทั้งสามแบบนี้เป็นพื้นฐานของกราฟิกเชิงโต้ตอบแบบ 2 มิติ
ทุกแบบทำงานบนพิกัดจุด (x, y) ของแต่ละพิกเซลในสไปรต์
1. Translation — การเลื่อนตำแหน่ง
ย้ายทุกจุดของวัตถุด้วยระยะ (tx, ty) เท่ากันทั้งหมด:
x' = x + tx
y' = y + ty
ในโปรเจกต์นี้ใช้ตำแหน่งเมาส์ (mouseX, mouseY) เป็นค่า (tx, ty) ทำให้สไปรต์เคลื่อนที่ตามเมาส์แบบเรียลไทม์
2. Rotation — การหมุน
หมุนจุดรอบจุดศูนย์กลางด้วยมุม θ โดยใช้สูตรตรีโกณมิติ:
x' = x·cos(θ) − y·sin(θ)
y' = x·sin(θ) + y·cos(θ)
ในโค้ดควบคุมมุมหมุนด้วยตัวแปร degree ที่เปลี่ยนค่าเมื่อกดลูกศรซ้าย/ขวา
3. Scale — การปรับขนาด
ขยายหรือย่อระยะห่างของจุดจากจุดศูนย์กลางด้วยตัวคูณ s:
x' = x · s
y' = y · s
ควบคุมด้วยตัวแปร scale ที่เพิ่ม/ลดเมื่อกดลูกศรขึ้น/ลง
